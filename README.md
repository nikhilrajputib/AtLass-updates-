# Atlass downloads

This repository contains installation metadata and binary releases for Atlass.

- Android ARM64: download `Atlass-1.8.2-android-arm64-v8a.apk` from the latest release.
- Windows x64: download `Atlass-1.8.2-windows-x64-setup.exe`; the installer includes the Java runtime and native libraries.

Website: https://atlass-website.vercel.app/

Creators: Nikhil and Prajjwal. Application source is not stored in this download repository.
