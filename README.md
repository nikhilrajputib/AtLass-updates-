# AtLas downloads

This repository contains public installer releases and download information. Application and website source are kept in separate private repositories.

- [Windows x64 installer](https://atlassmusic.vercel.app/download/windows) — includes the Java runtime and native libraries.
- [Android ARM64 APK](https://atlassmusic.vercel.app/download/android).
- [Current release and checksums](https://github.com/nikhilrajputib/AtLass-updates-/releases/latest).
- [AtLas website](https://atlassmusic.vercel.app).
- [iPhone and iPad availability](https://atlassmusic.vercel.app/ios) — no iOS installer is available yet.

The website download routes resolve the newest verified official installer. Superseded installer assets are retired after their replacement is verified.
